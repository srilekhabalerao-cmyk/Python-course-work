Python Tokens

Tokens are the smallest  unit of a Python program. Every Python program is made up of different types of tokens.

Types of Tokens

1. Identifiers: Identifiers are the names given to program elements such as variables, functions, classes, and objects. They are used to identify these elements in a program.

2. Keywords: Keywords are predefined words in Python that have a special meaning. They cannot be used as identifiers.

3. Literals: Literals are the fixed values used in a program, such as numbers, strings, and Boolean values.
Example: 10, "Hello", True

4. Operators: Operators are symbols used to perform operations on variables and values.
Examples: +, -, *, /, =, ==, >, <

5. Punctuators : Punctuators are symbols that separate or organize different parts of a Python program.
Examples: ( ) [ ] { } : , . ' ' " "

Rules for Identifiers

1. An identifier can contain uppercase letters (A–Z), lowercase letters (a–z), digits (0–9), and the underscore (_).
2. It cannot contain special characters such as @, #, $, %, etc.
3. An identifier must start with a letter (uppercase or lowercase) or an underscore (_). It cannot start with a digit.
4. Keywords cannot be used as identifiers.

Statements : A statement is a single instruction that Python executes.
Example: x = 10

Comments: Comments are used to explain the code. They are ignored by the Python interpreter.

Single-line Comment: A single-line comment starts with the # symbol.

Example: # This is a single-line comment

Multi-line Comment: they are written using triple quotes (''' ''' or """ """).

Example:
"""
This is a
multi-line comment.
"""
Variable Assignment: A variable is a named memory location used to store data. The process of storing a value in a variable is called variable assignment.
Keywords:Keywords are predefined (reserved) words in Python that have a special meaning. They are used by the Python interpreter to perform specific tasks. Keywords cannot be used as identifiers, such as variable names, function names, or class names.
