OOPS : Is a programming approach to organize using objects and classes 
features:
Encapsulations: Protects the data, wrapping data 
Inheritance : Inherits properties from parent to child 
Polymorphism: same actions different forms ( premium sub)
Abstraction: hides the complexities 
class: Blueprint(car)
method: function defined inside a class ( start, stop , accelerate)
instance: real world entity (car brand)
instance variable: belongs to object ,stores the data(color, model , price)
